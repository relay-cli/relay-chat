# Changelog

## 0.1.0

- Added the interactive Ink chat interface and multiline composer.
- Added streamed replies, cancellation, retry, regeneration, and edit-and-resend.
- Added Markdown-aware message rendering and conversation navigation.
- Added versioned save/load, Markdown export, autosave, and slash commands.
- Added the provider-neutral transport API and external JSON Lines bridge.
- Added deterministic demonstrations, plain mode, tests, and cross-platform build automation.
