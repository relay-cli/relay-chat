# Relay Chat artwork

The repository banner and social preview were generated with the built-in image-generation tool using the official Relay mark as the visual reference.

## Banner

`banner.png` uses a 3:1 composition. The left side contains the official Relay mark, product name, and a direct description. The right side depicts the real application structure: a user message, a streaming assistant message, and the multiline composer.

## Social preview

`.github/social-preview.png` recomposes the same approved interface for a 2:1 thumbnail. The supporting description is removed and the message labels remain large enough to read in repository cards.

Both prompts specify the shared Relay palette, monospace interface typography, restrained terminal borders, and the absence of agent, tool, provider, robot, and decorative-code imagery.
